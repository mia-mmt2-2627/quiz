# Quizzen — mia-mmt2-2627

Oefenquizzen: <https://mia-mmt2-2627.github.io/quiz/>

Deze repo is de publieke quizsite (GitHub Pages) en bevat **geen antwoorden**:
alleen de vragen en opties (`quizzes/*.json`), de pagina (`index.html`) en de
nakijkcode (`scripts/grade.mjs`, `.github/workflows/grade.yml`). De juiste
antwoorden en de feedback staan op een plek die alleen docenten kunnen zien.

Alles hier wordt automatisch gegenereerd vanuit `student-onboarding`
(workflow **Quiz publish**). Wijzigingen in deze repo worden bij de volgende
publicatie overschreven.
